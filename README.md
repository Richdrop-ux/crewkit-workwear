# CrewKit Workwear

Static, quote-only workwear catalogue.

## Publish and test

1. In Settings → Pages, choose Deploy from a branch, then main and / (root).
2. Submit a test quote on the published site. Open the FormSubmit activation email in crewkitworkwear@outlook.com and confirm the address.
3. Submit a second test and verify that the delivery postcode, customer email, and catalogue item details reach Outlook.

FormSubmit handles delivery and displays its confirmation page. The customer's email is available for replies. Edit the catalogue array in catalogue.js to add styles and confirm supplier stock before quoting.
