# CrewKit Workwear

Static, quote-only catalogue. Open index.html in a browser for a local preview.

## Launch

1. Set quoteEmail at the top of catalogue.js to your customer-facing CrewKit email. The button will open a prefilled email draft, which the customer sends from their email app. With no inbox configured the button downloads a text request.
2. Put index.html, style.css and catalogue.js at the root of a dedicated GitHub repository. In Settings → Pages, choose Deploy from a branch, then main and / (root).
3. Submit a test request from the published site and verify that it reaches your inbox. Customers can attach logos in their email app.

The catalogue includes six starter styles with supplier references. Edit the catalogue array in catalogue.js to add styles. Check current variants and availability before quoting. The list is saved in the visitor’s browser and there is no checkout or backend.
